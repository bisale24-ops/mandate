How it works

The model never decides whether money moves. PayPal's authorization is the commit protocol; the mandate is the only key to capture.

1
Hold

The agent's checkout becomes a PayPal order with intent AUTHORIZE: items, shipping and address are stored on the order and the money is held, not taken.

2
Check

Mandate reads the order back from PayPal and checks it against your request and the stores' own catalogs — never against what a web page told the agent.

3
Capture or void

A clean order is captured. Anything else is voided and the reasons go back to the agent, which can fix the order — so honest purchases still complete.

One line for PayPal's Agent Toolkit

The toolkit gives an agent create_order and pay_order. Mandate wraps the one method every framework dispatches through, so OpenAI Agents, LangChain, CrewAI and Bedrock agents all get the same guard.

# pip install paypal-agent-toolkit
from paypal_agent_toolkit.openai.toolkit import PayPalToolkit
from mandate.toolkit import guard
from mandate.policy import Mandate, Want

toolkit = PayPalToolkit(client_id, secret, configuration)
guard(toolkit.get_paypal_api(),
      Mandate.of("218.00", {"trailmart"}, home, [Want("TENT-STD", 1)]),
      catalog, merchant="trailmart")
# pay_order now captures only orders the mandate approves;
# a refusal comes back to the agent as the tool result, with the reasons.
